# IFLUTECH — Respaldo de aplicación web

Repositorio para conservar el código público de la interfaz web de IFLUTECH. **No contiene contraseñas ni una exportación de datos privados de la empresa.**

La versión de producción está en https://iflutech-almacen-web.vercel.app/ y utiliza Supabase como servicio de datos. El respaldo de la interfaz se guarda de manera comprimida y puede recuperarse con `python restaurar_web.py`.

**Estado:** desarrollo web pausado; prioridad actual: programa portable Windows. No utilizar como reemplazo de una copia de seguridad de la base de datos.
